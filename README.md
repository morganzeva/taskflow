# TaskFlow

TaskFlow est une petite application web de gestion de tâches. Elle permet d'ajouter, terminer, supprimer et filtrer ses tâches. Les données sont sauvegardées dans le navigateur grâce à `localStorage`.

## Aperçu

Application responsive réalisée sans framework, avec HTML, CSS et JavaScript.

## Fonctionnalités

- Ajouter une tâche (bouton ou touche Entrée)
- Marquer une tâche comme terminée
- Supprimer une tâche
- Filtrer les tâches : toutes, en cours ou terminées
- Afficher le nombre de tâches restantes
- Sauvegarder les tâches après actualisation de la page
- Interface adaptée aux mobiles

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (DOM, événements, tableaux, fonctions)
- Web Storage API (`localStorage`)

## Lancer le projet

Aucune installation n'est nécessaire.

1. Télécharger ou cloner le dépôt.
2. Ouvrir `index.html` dans un navigateur.
3. Ajouter quelques tâches pour tester les fonctionnalités.
